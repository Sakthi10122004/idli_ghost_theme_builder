# Idli Ghost Theme Builder

Idli Ghost Theme Builder is a robust, visual drag-and-drop editor for building themes for the Ghost blogging platform. Built with a modern stack including Next.js, Tailwind CSS, Zustand, and Prisma, it allows users to visually assemble theme layouts and compile them directly into standard Ghost Handlebars markup.

## Tech Stack
* **Framework**: Next.js 14+ (App Router)
* **Styling**: Tailwind CSS
* **State Management**: Zustand
* **Database**: Prisma ORM
* **Drag and Drop**: `@dnd-kit`

## Project Structure & File Explanation

This section explains the purpose of each top-level file and directory in this project.

### Directories

* **`src/`**: The main source code directory containing all application logic.
  * **`src/app/`**: Next.js App Router root. Contains API routes, global styles (`globals.css`), root layout (`layout.tsx`), and main pages.
  * **`src/components/`**: Reusable React UI components, specifically for the visual builder interface.
  * **`src/editor/`**: Contains the core logic for the visual editor. Includes the central block registry, canvas components, schemas, and compiler logic that translates visual blocks into Ghost `.hbs` code.
  * **`src/lib/`**: Utility functions and integrations, such as database client initialization (`db.ts`) and logging (`logger.ts`).
  * **`src/store/`**: Contains `editorStore.ts`, the Zustand state store that manages the visual editor's actions, node tree, and selection state.
  * **`src/types/`**: Shared TypeScript definitions, such as `theme.ts`, used across the application.
* **`prisma/`**: Contains the database schema (`schema.prisma`) and local development database files.
* **`public/`**: Publicly accessible static assets like images, fonts, or icons.
* **`scripts/`**: Utility scripts for build and deployment processes (e.g., `generate_casper_manifest.js` to compile Ghost theme metadata).
* **`doc/`**: Contains overarching project documentation and AI context files.
* **`logs/`**: Directory for storing local execution or application logs.

### Root Files

* **`AGENTS.md`**: AI Assistant instructions and rules. It specifies strict tech stack, architecture, validation, and design guidelines for AI agents working on this project.
* **`ARCHITECTURE.md`**: Provides a high-level overview of the system architecture and core concepts.
* **`DESIGN.md`**: Comprehensive UI and design system guidelines, defining colors, typography, spacing, and component aesthetics.
* **`ROADMAP.md`**: The project's milestones, current status, and planned future features.
* **`package.json` & `package-lock.json`**: Defines project metadata, scripts (`dev`, `build`, etc.), and strict dependency versions.
* **`tsconfig.json`**: TypeScript compiler configuration.
* **`next.config.ts`**: Configuration file for the Next.js framework.
* **`next-env.d.ts`**: TypeScript declaration file auto-generated by Next.js.
* **`eslint.config.mjs`**: Configuration for ESLint, ensuring code quality and style consistency.
* **`postcss.config.mjs`**: PostCSS configuration, primarily used for integrating Tailwind CSS.
* **`.env`**: Local environment variables configuration file (ensure not to commit sensitive data).
* **`.gitignore`**: Specifies intentionally untracked files that Git should ignore.

## Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run the Development Server**:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
